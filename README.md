### Задание 1

Активный master-сервер и пассивный репликационный slave
Повышенная отказоустойчивость (slave заменяет master при сбое), разделение нагрузки (master на запись, slave на чтение/бэкап), простота реализации без переписывания кода.

Master-сервер и несколько slave-серверов:
Масштабирование чтения (нагрузка распределяется по slaves), высокая доступность (множество копий данных), отказоустойчивость (любой slave может стать master), но возможны задержки синхронизации.
